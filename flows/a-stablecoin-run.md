Rung 3 of the [[failure-modes|failure ladder]], step by step. A stablecoin is a private dollar promise, and it can suffer the same kind of run as a bank.

| Step | Page |
|---|---|
| Holders start to doubt the reserves | [[stablecoins]] |
| The price slips below one dollar | [[stablecoins]] |
| Holders rush to redeem or sell | [[liquidity]] |
| The issuer sells reserve assets to pay them | [[t-bills]] |
| Exchanges and lending protocols holding the token are hit | [[defi]] |
| Tokens are frozen, redeemed in full, or left worth less | [[claims-and-liabilities]] |
